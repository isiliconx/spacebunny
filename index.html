How it was built

The demos were authored in parallel by a fleet of agents, then verified by rendering each one headlessly and measuring the result.

Rendered, then measured

A screenshot proves something drew, not that it drew correctly. Every demo sets window.__ready when its scene is live, and a small CDP harness waits for that flag, captures the frame, and reports colour count, clipping, and tonal spread. Verdicts are objective.

The bugs had no error messages

An inverted SDF sign collapsed an entire terrain to one flat plane. A pressure solver rendered into the texture it was sampling. sRGB colour values clamped as linear light turned every soft body pure white. All four presented as "looks slightly wrong" and all four were logic errors — only a render could catch them.

Calibrated by measurement

One demo was a featureless white disc. The cause was a 640×400 internal buffer — below one pixel per filament — plus exposure parked on the tonemap shoulder, where small input changes do nothing. A sweep scored candidates on tonal spread rather than brightness. 3,718 → 11,699 colours.

Reusable, not one-off

The verification harness lives in demos/tools/: a zero-dependency CDP renderer, an image health checker, a tiling detector, and a static self-containment audit. Run demos/tools/verify_all.sh to re-verify all eight in about eight minutes.

Built with three.js and raw WebGL2. Everything is procedural — regolith, fur, terrain, fluids, HDR environments.
