Menger Sponge

Each iteration replaces every cube with a cross of seven sub-cubes — a third removed from every face, at the same scale, forever.

The distance estimator tests every surviving sub-cube at each level and takes the nearest, so the march converges on the fractal rather than on the first level it finds. Recursion 3 costs 400 sub-cube evaluations per distance query, which exhausts the march budget on a software rasteriser, so 2 is the deepest setting that fully resolves.
